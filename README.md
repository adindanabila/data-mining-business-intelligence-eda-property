# data-mining-business-intelligence-eda-property
Data Mining and Business Intelligence project analyzing Indonesian property market data for strategic business decision-making.

# Data Mining dan Business Intelligence:
## EDA pada Data Property RPPI

## Background

PT Ray Pink Property Indonesia (RPPI) merupakan perusahaan property yang telah berdiri selama 11 tahun dan memiliki kantor cabang di 7 provinsi di Indonesia. Valuasi perusahaan pada tahun ini mencapai Rp 7 Triliun, meningkat sebesar 7% dibandingkan tahun sebelumnya. RPPI bergerak di bidang investasi serta jual-beli property, termasuk bekerja sama dengan developer perumahan.

Data Engineer (DE)/Database Administrator (DBA) RPPI telah berhasil mengumpulkan data rumah-rumah yang dijual di beberapa kota di Indonesia. Sebagai seorang Data Analyst di RPPI, dilakukan Exploratory Data Analysis (EDA) terhadap data tersebut untuk menghasilkan insight bisnis yang akan dipresentasikan kepada jajaran manajemen perusahaan, termasuk C-Level, senior managers, dan komisaris perusahaan.
